# 🍒 さくらんぼ たしざん｜玉から暗算へ（試作 v3.5）

小学校低学年向け、ブラウザで使う10のまとまりの足し算教材です。タブレットの指操作に対応しています。ファイルは `index.html` の1つで動き、ライブラリの読み込みやアカウント登録は不要です。

## 何ができる？

画面上部に **元の足し算（例：8＋5＝？）を常に表示**しながら、次の段階で少しずつヒントを減らします。

1. **① たま**：青玉をワンタップ（またはドラッグ）して10の箱を完成。残りの青玉を隠し、「9＝4＋□」のように表示。□に自分で数を入力してから和の選択肢へ進みます。
2. **② ず**：10マスの図を見て10まで必要な数を選び、次に分解した残りの数を数字入力してから、和を選びます。ヒントも利用できます。
3. **③ しき**：最初は10マスを隠し、「10にする数」→「残りの数（数字入力）」→「和」の順に考えます。ヒントで10マスを表示できます。
4. **④ じぶん**：式だけで計算し、選択肢ではなく数字キーで答えます。困ったら10マス→残りの数を隠したさくらんぼ図の順にヒントを表示します。
5. **🌱 おさらい**：前に練習した問題、とくに間違えたりヒントを使った問題を優先して10問復習する。自力モードと同じ数字入力方式。

**今回の大切な工夫**：「6＋9」なら、青玉4個を移して10が完成した時点で、残った青玉の画像・個数表示を隠し、「9＝4＋□」を表示。□の答え「5」は正しく入力するまで自動表示しません。そのあと「10＋5」の和を選びます。大きな式「6＋9＝？」は常に画面上部に残ります。

全モードは1回10問。正解すると次の問題へ。問題を間違えてもペナルティはありません。やり直し・段階の切り替えは自由です。

## v2.4：10問はそのまま、考え方を少し発展

- **🎯 きょうの10もん**：画面上部の大きなボタンから開始。過去の誤答・ヒント使用や、まだ解いたことのない問題を混ぜた10問を、数字で答えます。
- **ほかの練習**：玉・図・式・自力・おさらいの5モードは、折りたたみメニューから選べます。どのモードも10問。段階的に支援を減らす学習設計は維持します。
- **学習履歴の利用**：画面には成績の数字を出さず、端末内の直近の履歴を苦手問題の再出題に使います。

普段は「きょうの10もん」だけで始められます。難しいときはヒントを使い、必要に応じて玉や図のモードに戻れます。**速度は採点しません**。繰り返しの出題は簡易的な苦手・未経験問題の優先ルールであり、最適化された間隔反復アルゴリズムではありません。

### 新しく加わった内容（普段の画面にボタンは増やしません）

- **別の日の苦手問題を優先**：直近の履歴から、前の日にヒントを使った・初回で間違えた問題を最大3問、未経験の問題などと混ぜて出します。1回10問で、同一の式は重複しません。
- **文章題を2問**：10問中3問目と8問目に「ふうせん」「あめ」など短い文章を表示します。元の式も常時見せるため、文章から自力で立式する能力を判定する機能ではありません。
- **正解後の別の考え方を2回**：10問中4問目と9問目の正解後にだけ、加数の入れ替えや倍の数の利用を紹介します。答える前のヒントにはせず、読むだけで次へ進めます。
- **最初は自力、困ったらヒント**：「きょうの10もん」は和の数字入力から始め、必要な場合だけ10マス→さくらんぼの手助けを利用できます。

これらは認知負荷や使いやすさを考慮した**試作上の出題設計**で、最適な割合や学習効果は未検証です。「間隔を空けて復習」は暫定ルールであり、研究で検証された最適化アルゴリズムではありません。

## v2.9：1＋1〜10＋10の足し算表

画面上部に **「🍒 10もん れんしゅう」** と **「🔍 たしざんひょうの きまり」** の2つのタブがあります。

- 足し算表は縦1〜10、横1〜10の**100通り**。最大は10＋10＝20。答えが11以上の式も操作できるようになりました。
- 最初は「1＋○」「○＋1」にあたる19マスが表示され、それ以外の81マスは「？」。マスをタップして答えを見ます。
- **10の答え**は緑、**11〜20の答え**は紫。数の増え方、10を超える境目、加数の交換、斜めに並ぶ同じ答えを発見します。
- 低学年の子どもが100個の答えを丸暗記することは目標にしていません。まず「10になる組み合わせ」を理解し、**8＋2＝10から8＋3＝11**のように変化を見て説明できるようにする活動です。
- iPhoneなど画面の小さな端末では表の部分だけ左右にスクロールします。見出しの左列はスクロール中も見えるようにしています。
- 画面下の「もういちど さがす」で表をリセットできます。練習タブに戻っても進行中の10問は維持します。

表の発見活動は、正答率や学習履歴に含みません。通常の「きょうの10もん」は**10問固定**のままです。学習効果は未検証であり、可能であれば大人が「どうして1増えたの？」と問いかけて理解を確かめてください。

## v3.0：足し算表の下に赤玉・青玉での説明を追加

「🔍 たしざんひょうの きまり」タブで式をタップすると、表の説明の**下に**その式の赤玉・青玉と10マスの箱が表示されます。現在は選んだ式1つだけを表示し、前の式のカードは並べません（v3.2）。

- **2＋3と3＋2**：赤玉・青玉の数は入れ替わるが、合計は同じ。
- **8＋2と8＋3**：青玉が1個増える。8＋3では10マスの箱に赤8・青2が入り、外に青1が残る。
- **7＋3と6＋4**：赤と青の内訳が変わっても合計10。
- **10＋10**：10の箱に赤玉10個、外に青玉10個が残り、計20。
- 10マスの箱は**赤を先に、次に青を入れる図**とし、まだ10にならないときは空きマスを残します。10を超える青玉は箱の外として表示します。
- 「もういちど さがす」を押すと選んだ式と比較を初期化します。10問練習や以前の学習記録は変えていません。

見せる図は数の意味と規則の対応を学ぶための補助です。図を見ただけで理解・定着したと判断できるわけではありません。

## v3.1：1回タップの即時反映と、箱の外の青玉の可視化

- 規則性タブでは、マスをタップするたびに100個の表を作り直す処理を停止。**選んだマスだけをその場で更新**して、タッチ位置と横スクロールを保ちます。
- 「いま選んだ式」の説明を**表より上**に配置し、スクロール中も見えるようにしました。赤玉・青玉による詳しい説明は引き続き表の下に出ます。
- 8＋3では10の箱に赤8個・青2個、**箱の外に青玉1個を実際の丸で表示**します。10＋10でも外に青10個を描きます。
- 以前の学習記録や毎日の10問練習、足し算表100通りは変更していません。

※iPhone実機でのタップ動作は、更新後に操作を確かめる必要があります。モックDOMを使った関数テストでの確認結果をQA.mdに記載しています。

## v3.2：赤玉・青玉の説明を一枚だけにする

画面の見やすさを優先し、「ひとつまえ」の式のカードを自動表示する仕様を廃止。どのマスをタップしても、**今選んだ式の赤玉・青玉・10の箱だけ**を表示します。比較ボタンも増やしません。

足し算表の上にある短いメッセージは「10ができた」「1増えた」「順番を入れ替えても同じ」などの規則性を伝えるため維持します。**箱の外の青玉は引き続き丸で表示**し、10問練習も変更しません。

## v3.3：10問クリアでさくらんぼ農園が育つ

- **10問を最後まで解いて終了するごとに**農園が1段階成長します。途中で別モードに切り替えたり画面を閉じたりしても成長しません。1つの完了で重複して成長することはありません。
- 0：🌰 たね → 1：🌱 芽 → 2：🌿 葉 → 3：🪴 苗 → 4：🌳 木 → 5：🌸 花 → 6：🌼 実の準備 → 7：🟢 実 → 8：🍒 赤い実 → 9：🧺 収穫 → 10：🚚 出荷。
- **100問分（10回×10問）**の練習終了で出荷。出荷済みの状態は次の10問完了までそのまま残り、次の10問を完了すると新しい木の「芽」から始まります。
- 計算途中は練習タブ上の小さい農園表示のみ。成長の演出は10問を終えた画面だけで表示し、画面のボタンは増やしていません。
- 正誤やヒント使用の有無による減点はしません。10問完了したこと自体で育ちます。
- 農園の現在の段階は既存の計算履歴とは**別のブラウザ保存領域**（`sakuranbo-farm-v1`）に保持。過去の計算履歴から農園をさかのぼって成長させず、新機能導入後は0から始まります。保存不可の環境では画面を閉じると成長状態を引き継げません。
- 保護者欄の「この端末の学習記録と農園を消す」で確認後に両方を消去できます。

植物の成長段階はゲーム上の演出です。実際のサクランボ栽培に要する時間や農作業を正確に再現するものではありません。学力向上や動機づけへの効果は未検証です。

## v3.4（旧仕様）：1問ごとに実がついた試作

- 以前の画面イメージの「今日の10問 6/10、木の実が6個」という分かりやすさを取り入れ、農園の小さなステータスに**さくらんぼの木のイラスト**を追加。
- **正解を確定するたびに**木の実が1個増え、下の10個のバーも1つ埋まります。例えば6問解いたら実は6個、バー6/10、画面には「あと4もんで みが いっぱい！」と表示します。
- 10問を解き終えると実が10個になり、**これまでどおり農園全体も1段階成長**します。累計10セッションで収穫・出荷に到達する長期の進行は維持。
- 間違えただけでは進まず、**ヒントを使って正解した問題も同じく1個増えます**。10問の途中で練習を切り替えたり再開したりした場合、その回の木の実だけ0から数え直します。長期成長には影響しません。
- イラストはアプリ内に埋め込んだSVGで、外部の画像や通信は不要。花火や音を増やさず、成長した実だけを短く表示します。端末の「動きを減らす」設定にも対応しています。
- 練習画面を圧迫しないよう木はコンパクトに表示。大きな成長のお祝いは10問完了画面に限定しています。

画像にある暗い背景の配色はそのまま複製せず、既存の淡い配色に馴染むように実装しました。iPhoneでの実表示・操作感は使用端末で確認してください。

## v3.5：種から育ち、10個の実がそろった瞬間に出荷

- **最初に木はありません。** 農園画面には種だけが現れます。10問完了で芽、20問完了で苗木、30問完了で花の咲く木へ成長します。
- 以降は10問完了ごとに木に**実を1個ずつ追加**。40問で実1個、130問（13セッション）で実10個となり、その**最後の実が付いた瞬間に出荷演出**を表示します。出荷のためだけの追加10問は不要です。
- 同じSVGの木が成長段階に応じて姿を変えます。1つの実は1個の赤い丸で描画。端末で動きを減らす設定を使用している場合は演出を抑えます。
- **1問ごとの進捗は数字と10分割のバーだけ**にして、木の実は増やしません。10問を最後まで終えたときだけ農園の木が変わります。
- 出荷した状態は保存・再読み込み後も維持。次の10問練習を**ユーザーが開始した時点**で新しい種へ戻り、完了時に次の芽が出ます。
- 既存の `sakuranbo-farm-v1` の育成段階（0〜10）は、別の保存キー `sakuranbo-farm-v2` に移行して引き継ぎます。旧段階10（出荷済み）は新段階13（出荷済み）として扱います。旧データは自動削除しません。
- 保護者向け「この端末の学習記録と農園を消す」は確認後に旧・新の農園記録も消去します。従来の回答履歴は練習用として保存され、算数の出題方式・10問固定・足し算表は変更していません。

これは育成を楽しむための**ゲーム上の表現**です。実際のサクランボの栽培期間を表すものではなく、学習効果や継続率の改善は未検証です。

## 次の段階への移行

各段階の最後5問中、4問以上で「初回正解・ヒントなし」だった場合は、次の段階を**試す提案**が出ます。自動昇格・ロック・能力診断ではありません。これはアプリ内での暫定基準で、学術研究が裏付ける一律の合格ラインではありません。

大人がそばで「どうして8＋5が10＋3になる？」と聞き、子どもの説明を確かめることも大切です。玉なしで解けるかどうかは、**別の日や紙で初見の問題**を解いたときにも確認してください。

## GitHub Pagesに公開する手順

1. GitHubに新しいリポジトリを作成（例：`sakuranbo-learning`）。
2. このフォルダの `index.html`、`README.md`、`.nojekyll`、`QA.md` を直下に置いてコミット。
3. GitHubの `Settings → Pages → Build and deployment` で `Deploy from a branch`、`main`、`/(root)` を指定。
4. 生成された `https://<username>.github.io/<repository>/` にアクセス。
5. 娘さんのiPadのSafariで、①玉のワンタップ→②図→③式→④数字入力→おさらい→画面再読込後の記録まで試す。

既存のGitHub Pagesリポジトリを使う場合は `index.html` を新版に差し替えればよいです。GitHubへのアップロードや公開設定の変更はこのZIPだけでは行いません。

## 画面のシンプル化と記録の取り扱い

子どもの画面から「今日の学習記録」と7日間のグラフ・モードごとの数値表示を外しました。**苦手問題を別日に出すための匿名の計算履歴は、従来どおりこの端末内に保存します。** 既存の保存データは削除していません。「おうちのひとへ」にある「この端末の学習記録を消す」で、利用者が明示的に削除できます。記録の保存そのものを無効化した版ではありません。

## 記録とプライバシー

- 記録項目：日付、出題した数字、モード、初回正解か、ヒント・誤答の有無。
- `localStorage` に最大300問分を保存。画面には日々の成績や7日間のグラフを表示しません。使うブラウザ・端末に依存し、消去されることがあります。
- 名前・写真・学校名・個人アカウントは取得しません。教材のJavaScriptに外部通信処理はありません。公開サーバーへの通常アクセス通信は別です。
- 親向け欄の「学習記録を消す」で履歴を消去できます。**削除は取り消せません**。

## 教育研究上の位置づけ

この教材は、具体物（玉）→図→式→支援なしへ進む設計です。具体物と数式を結びつけ、支援を段階的に減らす方向性は教育研究と整合していますが、**このアプリの成績改善や定着効果は未検証**です。
